# Инструкция по запуску (Practice 05)

Эта инструкция описывает запуск и проверку реализованной фичи пагинации и серверной сортировки в учебном сервисе Notify Mini.

## Что это и где код
- Бэкенд/фронтенд демо: `practices/practice_03/lab/demo/`
- Сервер: `http_server.py` (Python stdlib: http.server)
- Фронтенд: `web/index.html`, `web/script.js`, `web/style.css`
- Логика подписчиков: `service.py`

## Требования
- Python 3.10+ (без внешних зависимостей)
- macOS/Linux/WSL; команды приведены для `make`

## Быстрый старт (сервер + UI)
1. Запустите сервер (отдаёт API и статику UI):
   ```bash
   make -C "practices/practice_03/lab/demo" serve
   ```
2. Откройте браузер: http://127.0.0.1:8000/
3. В UI доступны:
   - Таблица со списком подписчиков
   - Пейджер: «Первая», «Предыдущая», номера страниц, «Следующая», «Последняя»
   - Сортировка по направлению asc/desc (ключ `created_at` фиксирован на сервере)
   - Лоадер и блокировка контролов во время запросов
   - Сообщения об ошибках (400/5xx) и кнопка «Применить исправления» для некорректных параметров

Примечания:
- Состояние хранится в памяти процесса и очищается при перезапуске.
- Путь проекта содержит пробелы — используйте кавычки в командах (как в примерах).

## API (контракт)
- Списочный эндпоинт (REST):
  - `GET /api/v1/subscribers?offset={0+}&limit={1..100}&sort=asc|desc`
  - Ответ 200 OK: строго `{ "items": [...], "total": <number> }` (только два верхнеуровневых поля)
  - Ошибка 400 (валидация): `{ "error": { "code": "VALIDATION_ERROR", "message": "...", "details": { ... } } }`
  - Ошибка 500 (внутренняя): `{ "error": { "code": "INTERNAL_ERROR", "message": "...", "details": {} } }`
  - Тестовый хук для 500: добавьте `__test_internal=1` в query
- Совместимость: `GET /api/subscribers` (legacy) возвращает `{ "subscribers": ["..."] }` для старого UI

## Тесты
1. Юнит и контрактные тесты:
   ```bash
   make -C "practices/practice_03/lab/demo" test
   ```
   Покрывают: subscribe/unsubscribe, формат `{items,total}`, 400/500.
2. Сквозные проверки (E2E):
   ```bash
   make -C "practices/practice_03/lab/demo" e2e
   ```
   Результаты сохраняются в:
   - `practices/practice_03/lab/demo/results_e2e.md`
   - `practices/practice_03/lab/demo/result.md`

## Траблшутинг
- Порт 8000 занят:
  ```bash
  python3 -c 'import http_server; http_server.serve(port=8080)'
  # затем откройте http://127.0.0.1:8080/
  ```
- Видите 400 VALIDATION_ERROR:
  - В UI нажмите «Применить исправления» — параметры будут автоматически приведены к допустимым (offset ≥ 0, 1 ≤ limit ≤ 100, sort ∈ {asc, desc}).
- Пустая страница при наличии данных (offset вышел за границы):
  - UI автоматически сместится на последнюю валидную страницу и перезапросит данные.
