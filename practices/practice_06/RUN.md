# Практика 6 — Инструкция по запуску

Мини‑сервис магазина (Mini Shop) написан на Python 3.10+ и использует только стандартную библиотеку. Тесты и запуск выполняются через Makefile‑таргеты.

## Требования

- Python 3.10 или новее
- Доступен интерпретатор `python3`
- Интернет не требуется; внешние пакеты не устанавливаются

## Быстрый старт (из корня репозитория)

1. Проверка окружения:

```
make -C practices/practice_06 install
```

2. Запуск тестов:

```
make -C practices/practice_06 test
```

3. Запуск сервера:

```
make -C practices/practice_06 run
```

Сервер слушает только `127.0.0.1` и печатает адрес, например:

```
Local exercise: http://127.0.0.1:8066
Disposable fixture files: /tmp/itmo-practice-06-XXXXX
```

Остановить сервер — `Ctrl+C` в терминале.

## Альтернативно: из каталога lab

```
cd practices/practice_06/lab
make install
make test
make run
```

Или напрямую:

```
python3 service.py --port 8066
```

Порт можно изменить, например `--port 8080`. Если порт занят, выберите другой. Для выбора свободного порта автоматически используйте `--port 0` (система назначит порт и он будет выведен в консоль).

## Проверка вручную (HTTP)

Пара примеров запросов после запуска сервера:

- Проверка состояния:
```
curl http://127.0.0.1:8066/health
```

- Логин и покупка:
```
# Логин (alice)
curl -s -X POST http://127.0.0.1:8066/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"alice","password":"learn-alice"}'

# Используйте полученный token в X-Token
curl -s -X POST http://127.0.0.1:8066/orders \
  -H 'Content-Type: application/json' \
  -H 'X-Token: <token>' \
  -d '{"product":"chair"}'
```

## Примечания

- Файлы стенда находятся в временной директории и пересоздаются при каждом запуске; данные синтетические.
- HTTP‑процесс привязан к `127.0.0.1` и недоступен из сети.
- Для staff‑операций используйте пользователя `staff` с паролем `learn-staff`.
