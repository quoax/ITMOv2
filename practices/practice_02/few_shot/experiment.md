# Few-shot

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Артефакт Практики 1: practices/practice_01/tests_load.md
- Что хотим улучшить: сделать проверяемым; согласовать статусы

## Примеры

### Хороший результат

Описана конкретная нагрузка и пределы с воспроизводимыми командами и ожидаемыми распределениями статусов. Например: «POST /api/reviews 10 rps, 60 сек, LLM замокан, ожидаем P95 ≤ 200 мс, error rate = 0%, статус-коды только 2xx».

### Плохой результат

Размытые формулировки без инструментов: «сервис должен выдерживать высокую нагрузку», «без деградации», без чисел и без указания статусов.

## Запрос

Собери для tests_load.md три проверяемых сценария с конкретными порогами и командами запуска без внешних зависимостей вроде jq. Контекст: учебный FastAPI-сервис /api/reviews, вход ReviewRequest, ошибки: 422 при нарушении схемы, 502 при сбое LLM. Используй hey или wrk; для wrk приведи минимальный скрипт Lua прямо в markdown. Для каждого сценария зафиксируй: нагрузку, допустимый предел P95, ожидаемые статусы и как проверяется отсутствие лишних 5xx.

## Что получили

1. POST /api/reviews с коротким diff: 10 rps, 60 сек, мок LLM, ожидаем P95 ≤ 200 мс, статусы 2xx, ошибки 0%.
   - Команда hey: `hey -z 60s -q 10 -m POST -H 'Content-Type: application/json' -d '{"diff":"x"}' http://localhost:8000/api/reviews`
   - Альтернатива wrk: `wrk -t2 -c20 -d60s -s scripts/review_valid.lua http://localhost:8000`

2. Валидация 422 под нагрузкой: 20 rps, 30 сек, payload без diff, ожидаем 100% 422, P95 ≤ 50 мс.
   - Команда hey: `hey -z 30s -q 20 -m POST -H 'Content-Type: application/json' -d '{}' http://localhost:8000/api/reviews`

3. Стабильность при 502: 5 rps, 60 сек, LLM всегда timeout, ожидаем 100% 502, P95 ≤ 300 мс, без роста lat >20%.
   - Команда hey: `HEY_LLM_TIMEOUT=1 hey -z 60s -q 5 -m POST -H 'Content-Type: application/json' -d '{"diff":"x"}' http://localhost:8000/api/reviews`
   - Примечание: вместо переменной окружения допускается мок адаптера в тестовом стенде.
